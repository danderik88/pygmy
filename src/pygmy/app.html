Looking for printers on the network…

Pygmy checks what answers at that address: a Klipper printer (Moonraker) or one that needs an access code.

Pygmy finds Klipper printers when Moonraker answers on port 7125 (Mainsail or Fluidd running means it does). Temperature limits come from the printer's own printer.cfg.

On the printer: Settings, Network, turn on LAN-only mode and Developer Mode. The access code is on the same screen.

Put a USB stick or SD card (FAT32) in the printer: Pygmy sends prints to it. Newer printers (P2S, H2 series) keep files in internal memory that Pygmy can't reach, so they need one too.

On the printer: Settings → Network → Access code
